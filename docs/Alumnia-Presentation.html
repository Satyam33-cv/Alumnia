2 Proposed Solution — Detailed

One API · Three surfaces · Full referral engine

  • Single Express + Prisma API (JWT-secured) powers Next.js web, React Native mobile & any future client — 100% shared logic.
  • Referral engine: student requests with resume upload + note → alumni accept/reject → referred → hired, with in-app + email + WhatsApp alerts at every step.
  • Engagement suite: job board, alumni directory (batch/dept/company/location), story Spotlight Wall + admin approval, events + RSVP with capacity, faculty announcements.
  • Admin command center: analytics (KPIs, users by role, referrals by status), verification, CSV bulk import, story review queue.
  • AI Smart Matching: 384-dim profile embeddings (OpenAI, local fallback) + pgvector HNSW cosine ranking → "Top 5 Alumni for You".
Student ─→ request (resume+note) ─→ Alumni ─→ accept/reject ─→ referred ─→ hired
       └─→ notification bell + email + WhatsApp at every step

Innovation & uniqueness

  • Graceful degradation — email/WhatsApp/Cloudinary/OpenAI all optional; nothing ever breaks.
  • Portable self-owned JWT auth — no platform lock-in.
  • One backend, three surfaces — web + mobile + API clients.

4 Feasibility & Viability

Technical
Mature, free-tier stack. One Node server + one Postgres DB (free Supabase/Neon) is enough to launch.
Economic
Near-zero marginal cost — all external services optional & degrade gracefully; fully self-hostable.
Operational
One-command migrations + seed; deployment playbook in docs/DEPLOYMENT.md.
Time
All 6 phases built and verified with per-phase deliverables + documentation.

Challenges, risks & strategies

Challenge / RiskStrategy to overcome
No live database during developmentGraceful fallbacks; migrations + seed verified for one-command DB bring-up
Missing external API keysPlaceholder mode — console logs, local files, local embeddings; everything testable
Cold-start AI matchingAdmin "Sync embeddings" endpoint; deterministic local fallback without OpenAI
Local uploads wiped on redeployCloudinary required in production (documented + env template)
Mobile can't reach APIAPI_URL env resolution: emulator 10.0.2.2, LAN IP, production HTTPS
Bad / legacy alumni dataCSV bulk import with temp password + admin verification workflow
